Affect labeling · обозначение аффекта словом

Проговаривание эмоции снижает её физиологический отклик ещё до анализа причин

Мысль без точного слова для чувства не задействует тот же регулирующий механизм

Это явление назвали affect labeling, обозначение аффекта словом. С тех пор эффект был воспроизведён в десятках последующих исследований на разных группах людей. Проговаривание эмоции в буквальном смысле снижает интенсивность её физиологического отклика, ещё до какого-либо анализа причин. Это и есть механизм, который мы будем использовать в этой лекции. Не для того, чтобы «выговориться» в разговорном смысле этого слова, а чтобы физиологически снизить накал непрожитой эмоции и сделать её доступной для работы, а не только для бегства от неё. Пропуск этого шага, кстати, одна из причин, почему одного лишь «подумать о проблеме» часто недостаточно: мысль без точного слова для чувства не задействует тот же самый регулирующий механизм.
